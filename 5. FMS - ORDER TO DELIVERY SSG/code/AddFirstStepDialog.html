Add First Step (creates the entry form)

One dialog. Creates a Google Form for capturing new process entries, links it to this spreadsheet, writes the form-data columns and INDEX formulas, and lays out the entry-event header (Step 1 in the FMS).

Heads up: Run "Setup (First Time)" first if you haven't yet. This wizard will be refused if office hours / working days aren't configured.
Process
Used in the form title. e.g. "Purchase Order — FMS Entry Form".
Form fields (info captured at process start)
Keep it minimal. Just enough to identify each item: e.g. PO Number, Vendor Name, Quantity. Don't add reference data (phone numbers, GST, full addresses) — that belongs elsewhere.
First step (the entry event)
The first step is whatever triggers a new process instance. Examples: "Generate PO", "Receive Order Inquiry", "Patient Walks In", "Hire Request Raised".
The person who fills the form when the process starts.
Where they get the info from (the source system or method).
When: Whenever Needed.
The first step is always the entry event — it has no deadline of its own. The form's submission timestamp (column A) acts as its Actual time, and every subsequent step's timing flows forward from there.
